## Default Permission

Every command: all of @capacitor-firebase/crashlytics's API, as the Capacitor plugin exposes it

#### This default permission set includes the following:

- `allow-crash`
- `allow-set-custom-key`
- `allow-set-user-id`
- `allow-log`
- `allow-set-enabled`
- `allow-is-enabled`
- `allow-did-crash-on-previous-execution`
- `allow-send-unsent-reports`
- `allow-delete-unsent-reports`
- `allow-record-exception`
