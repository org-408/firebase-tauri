# firebase-tauri

[Tauri 2](https://tauri.app) plugins for [Firebase](https://firebase.google.com) Analytics and Crashlytics on iOS and
Android: ports of [`@capacitor-firebase/analytics`](https://github.com/capawesome-team/capacitor-firebase) and
`@capacitor-firebase/crashlytics` that keep their API (same method names, arguments and results), so an app moving from
Capacitor to Tauri Mobile only changes an import.

| Package | Port of |
| --- | --- |
| Analytics | `@capacitor-firebase/analytics` |
| Crashlytics | `@capacitor-firebase/crashlytics` |

Status: **in development, not published yet.** The first release targets `@capacitor-firebase/*` 8.6.0.

This is an independent community project. It is not affiliated with or endorsed by Google, the Tauri Programme or
Capawesome. It is not an official Tauri plugin.
